## Architectural Summary

The editor is a standalone executable that links all engine libraries plus ImGui, ImGuizmo, and nfd (native file dialog). It is the only target in the entire project that touches ImGui -- no engine library (helios-core, helios-renderer, helios-physics, helios-audio, helios-script) may include any ImGui header or reference any ImGui type.

The current editor (`Editor/src/`) is a monolithic Layer class (`EditorLayer`) that manually calls singleton renderers, static panel classes, and raw `new` allocations. The rewrite converts every piece into ECS systems that receive their data through system parameters (queries, resources, events, commands).

**Key differences from current code:**
- No singletons. SceneGraph, ContentBrowser, Viewport, etc. are free-function systems, not static classes.
- No raw `new`. No `Ref<T>` / `CreateRef`. Plain data in resources, RAII value types.
- Undo/redo is a first-class `EditorCommands` resource, not absent.
- ImGui initialization uses the RHI escape hatch (`native_handle<VkDevice>()`, `native_handle<GLFWwindow*>()`), not direct Vulkan globals.
- Play/Stop uses World snapshot/restore, not `Scene::Copy`.
- Inspector uses qlibs/reflect for automatic field iteration, not per-component manual UI lambdas.

**New directory structure:**

```cpp
#include <helios/app/app.h>
#include <helios/window/window_plugin.h>
#include <helios/input/input_plugin.h>
#include <helios/renderer/forward_plus_plugin.h>

#include <filesystem>
#include <string>

int main(int argc, char** argv) {
    // Parse project path from command line (*.hveproject file)
    std::filesystem::path project_path;
    for (int i = 1; i < argc; ++i) {
        std::filesystem::path arg{argv[i]};
        if (arg.extension() == ".hveproject") {
            project_path = arg;
            break;
        }
    }

    // Fallback: look for SandBox project in current directory
    if (project_path.empty()) {
        auto fallback = std::filesystem::current_path() / "SandBox" / "SandBox.hveproject";
        if (std::filesystem::exists(fallback)) {
            project_path = fallback;
        }
    }

    std::string window_title = "Helios Editor";
    if (!project_path.empty()) {
        window_title = project_path.stem().string() + " - Helios Editor";
    }

    helios::App app;

    // Engine plugins
    app.add_plugin<helios::WindowPlugin>({
        .title = window_title,
        .width = 1920,
        .height = 1080,
        .maximized = true,
        .vsync = false,
    });
    app.add_plugin<helios::InputPlugin>();
    app.add_plugin<helios::ForwardPlusPlugin>();
    app.add_plugin<helios::PhysicsPlugin<helios::JoltBackend>>();
    app.add_plugin<helios::AudioPlugin<helios::SoLoudBackend>>();
    app.add_plugin<helios::ScriptingPlugin>();

    // Editor-only plugin (adds ImGui, panels, undo/redo, gizmos)
    app.add_plugin<helios::editor::EditorPlugin>({
        .project_path = project_path,
    });

    app.run();
    return 0;
}
```

## Task 4: EditorCommands -- Undo/Redo System (`helios-editor/src/editor_commands.h`, `.cpp`)

Type-erased undo/redo stack. Every mutation the editor makes to the World goes through `EditorCommands` so it can be reverted. Uses `std::function<void(World&)>` for apply/revert closures.

- [ ] Create `helios-editor/src/editor_commands.h`
- [ ] Create `helios-editor/src/editor_commands.cpp`

```cpp
// helios-editor/src/editor_commands.h
#pragma once

#include <helios/ecs/world.h>
#include <helios/ecs/entity.h>

#include <functional>
#include <string>
#include <vector>

namespace helios::editor {

class EditorCommands {
public:
    struct UndoEntry {
        std::string description;             // Human-readable (e.g. "Set Transform.position")
        Entity entity;                       // Entity affected (INVALID for non-entity ops)
        std::function<void(World&)> apply;   // Apply the change
        std::function<void(World&)> revert;  // Revert to previous state
    };

    // Modify a component field: captures old value, applies new value, pushes undo entry.
    // T must be copyable (all components are plain aggregates).
    template<typename T>
    void set(Entity entity, World& world, const T& new_value,
             const std::string& description = "Set component") {
        T old_value = world.get<T>(entity);

        // Truncate redo history when a new action is performed
        m_entries.resize(m_cursor);

        m_entries.push_back(UndoEntry{
            .description = description,
            .entity = entity,
            .apply = [entity, new_value](World& w) {
                w.get<T>(entity) = new_value;
            },
            .revert = [entity, old_value](World& w) {
                w.get<T>(entity) = old_value;
            },
        });

        // Apply immediately
        world.get<T>(entity) = new_value;
        m_cursor = m_entries.size();
    }

    // Record a custom operation (spawn/despawn entity, add/remove component, etc.)
    void execute(UndoEntry entry, World& world);

    // Undo the last operation. Returns true if an operation was undone.
    bool undo(World& world);

    // Redo the last undone operation. Returns true if an operation was redone.
    bool redo(World& world);

    bool can_undo() const { return m_cursor > 0; }
    bool can_redo() const { return m_cursor < m_entries.size(); }

    // Get description of the operation that would be undone/redone
    const std::string& undo_description() const;
    const std::string& redo_description() const;

    // Clear all history (e.g. on scene load)
    void clear();

    // History inspection
    size_t history_size() const { return m_entries.size(); }
    size_t cursor() const { return m_cursor; }

private:
    std::vector<UndoEntry> m_entries;
    size_t m_cursor = 0;  // Points to the next entry to be written (past the last applied)
};

} // namespace helios::editor
```

```cpp
// helios-editor/src/editor_commands.cpp
#include "editor_commands.h"

namespace helios::editor {

void EditorCommands::execute(UndoEntry entry, World& world) {
    // Truncate redo history
    m_entries.resize(m_cursor);

    // Apply the operation
    entry.apply(world);

    m_entries.push_back(std::move(entry));
    m_cursor = m_entries.size();
}

bool EditorCommands::undo(World& world) {
    if (!can_undo()) return false;

    --m_cursor;
    m_entries[m_cursor].revert(world);
    return true;
}

bool EditorCommands::redo(World& world) {
    if (!can_redo()) return false;

    m_entries[m_cursor].apply(world);
    ++m_cursor;
    return true;
}

const std::string& EditorCommands::undo_description() const {
    static const std::string empty;
    if (!can_undo()) return empty;
    return m_entries[m_cursor - 1].description;
}

const std::string& EditorCommands::redo_description() const {
    static const std::string empty;
    if (!can_redo()) return empty;
    return m_entries[m_cursor].description;
}

void EditorCommands::clear() {
    m_entries.clear();
    m_cursor = 0;
}

} // namespace helios::editor
```

**Differs from current code:** The old editor has zero undo/redo. All panel mutations directly modify components. The new `EditorCommands` interposes on every mutation.

**Verification:** Unit tests in Task 16 exercise the undo/redo cursor logic.

## Task 5: ImGuiRenderPlugin (`helios-editor/src/imgui/imgui_render_plugin.h`, `.cpp`)

- [ ] Create `helios-editor/src/imgui/imgui_render_plugin.cpp`

```cpp
// helios-editor/src/imgui/imgui_render_plugin.h
#pragma once

#include <helios/app/app.h>

namespace helios::editor {

// Resource holding ImGui-specific Vulkan objects (descriptor pool, render pass).
// Destroyed in reverse order on shutdown.
struct ImGuiContext {
    bool initialized = false;
    // Vulkan handles owned by ImGui backend -- cleaned up via ImGui_ImplVulkan_Shutdown
    // No raw VkDescriptorPool etc. stored here; the ImGui Vulkan backend owns them.
};

struct ImGuiRenderPlugin {
    void build(App& app);
};

} // namespace helios::editor
```

```cpp
// helios-editor/src/imgui/imgui_render_plugin.cpp
#include "imgui_render_plugin.h"

#include <helios/ecs/world.h>
#include <helios/renderer/rhi/device.h>
#include <helios/renderer/render_thread.h>
#include <helios/window/windows.h>

#include <imgui.h>
#include <imgui_impl_glfw.h>
#include <imgui_impl_vulkan.h>

#include <vulkan/vulkan.h>
#include <GLFW/glfw3.h>

namespace helios::editor {

// ---- Startup system: runs once ----

static void init_imgui(
    Res<rhi::Device> device,
    Res<Windows> windows,
    ResMut<ImGuiContext> ctx
) {
    IMGUI_CHECKVERSION();
    ImGui::CreateContext();

    ImGuiIO& io = ImGui::GetIO();
    io.ConfigFlags |= ImGuiConfigFlags_DockingEnable;
    io.ConfigFlags |= ImGuiConfigFlags_ViewportsEnable;  // Multi-viewport (optional)
    io.ConfigFlags |= ImGuiConfigFlags_NavEnableKeyboard;

    // Style
    ImGui::StyleColorsDark();
    ImGuiStyle& style = ImGui::GetStyle();
    if (io.ConfigFlags & ImGuiConfigFlags_ViewportsEnable) {
        style.WindowRounding = 0.0f;
        style.Colors[ImGuiCol_WindowBg].w = 1.0f;
    }

    // ----- RHI escape hatch: extract native handles -----
    // The engine's rhi::Device and Windows expose native_handle<T>() methods
    // specifically so editor-only code (like ImGui) can initialize backends
    // without the engine needing to know about ImGui.

    auto* glfw_window = static_cast<GLFWwindow*>(windows->primary().native_handle());
    ImGui_ImplGlfw_InitForVulkan(glfw_window, true);

    // Vulkan backend initialization.
    // native_handle<T>() returns the raw Vulkan objects needed by imgui_impl_vulkan.
    VkInstance instance       = device->native_handle<VkInstance>();
    VkPhysicalDevice phys_dev = device->native_handle<VkPhysicalDevice>();
    VkDevice vk_device        = device->native_handle<VkDevice>();
    uint32_t queue_family     = device->graphics_queue_family();
    VkQueue graphics_queue    = device->native_handle<VkQueue>();

    // Create a descriptor pool for ImGui
    // (The pool is large enough for ImGui's internal allocations)
    VkDescriptorPoolSize pool_sizes[] = {
        { VK_DESCRIPTOR_TYPE_SAMPLER, 1000 },
        { VK_DESCRIPTOR_TYPE_COMBINED_IMAGE_SAMPLER, 1000 },
        { VK_DESCRIPTOR_TYPE_SAMPLED_IMAGE, 1000 },
        { VK_DESCRIPTOR_TYPE_STORAGE_IMAGE, 1000 },
        { VK_DESCRIPTOR_TYPE_UNIFORM_TEXEL_BUFFER, 1000 },
        { VK_DESCRIPTOR_TYPE_STORAGE_TEXEL_BUFFER, 1000 },
        { VK_DESCRIPTOR_TYPE_UNIFORM_BUFFER, 1000 },
        { VK_DESCRIPTOR_TYPE_STORAGE_BUFFER, 1000 },
        { VK_DESCRIPTOR_TYPE_UNIFORM_BUFFER_DYNAMIC, 1000 },
        { VK_DESCRIPTOR_TYPE_STORAGE_BUFFER_DYNAMIC, 1000 },
        { VK_DESCRIPTOR_TYPE_INPUT_ATTACHMENT, 1000 },
    };

    VkDescriptorPoolCreateInfo pool_info{};
    pool_info.sType = VK_STRUCTURE_TYPE_DESCRIPTOR_POOL_CREATE_INFO;
    pool_info.flags = VK_DESCRIPTOR_POOL_CREATE_FREE_DESCRIPTOR_SET_BIT;
    pool_info.maxSets = 1000;
    pool_info.poolSizeCount = static_cast<uint32_t>(std::size(pool_sizes));
    pool_info.pPoolSizes = pool_sizes;

    VkDescriptorPool imgui_pool;
    vkCreateDescriptorPool(vk_device, &pool_info, nullptr, &imgui_pool);

    // ImGui Vulkan init
    ImGui_ImplVulkan_InitInfo init_info{};
    init_info.Instance = instance;
    init_info.PhysicalDevice = phys_dev;
    init_info.Device = vk_device;
    init_info.QueueFamily = queue_family;
    init_info.Queue = graphics_queue;
    init_info.DescriptorPool = imgui_pool;
    init_info.MinImageCount = 2;
    init_info.ImageCount = 2;       // Adjusted by swapchain image count at runtime
    init_info.MSAASamples = VK_SAMPLE_COUNT_1_BIT;
    // RenderPass is set from the swapchain's render pass or a dedicated ImGui pass
    // The render thread provides this via the FramePacket's imgui render pass.

    ImGui_ImplVulkan_Init(&init_info);

    // Upload fonts
    ImGui_ImplVulkan_CreateFontsTexture();

    ctx->initialized = true;
}

// ---- Per-frame system: begins ImGui frame ----

static void begin_imgui_frame(Res<ImGuiContext> ctx) {
    if (!ctx->initialized) return;

    ImGui_ImplVulkan_NewFrame();
    ImGui_ImplGlfw_NewFrame();
    ImGui::NewFrame();
}

// ---- Per-frame system: ends ImGui frame, packs draw data for render thread ----

static void end_imgui_frame(
    Res<ImGuiContext> ctx,
    ResMut<FramePacket> packet
) {
    if (!ctx->initialized) return;

    ImGui::Render();

    // The FramePacket has an optional imgui_draw_data field.
    // We clone the ImDrawData into the packet so the render thread can
    // submit it independently. ImGui::GetDrawData() is only valid until
    // the next NewFrame, so we must copy it now.
    ImDrawData* draw_data = ImGui::GetDrawData();
    if (draw_data && draw_data->CmdListsCount > 0) {
        packet->imgui_draw_data = clone_imgui_draw_data(draw_data);
    }

    // Multi-viewport update (if enabled)
    ImGuiIO& io = ImGui::GetIO();
    if (io.ConfigFlags & ImGuiConfigFlags_ViewportsEnable) {
        ImGui::UpdatePlatformWindows();
        ImGui::RenderPlatformWindowsDefault();
    }
}

// ---- Shutdown system ----

static void shutdown_imgui(ResMut<ImGuiContext> ctx, Res<rhi::Device> device) {
    if (!ctx->initialized) return;

    device->wait_idle();
    ImGui_ImplVulkan_Shutdown();
    ImGui_ImplGlfw_Shutdown();
    ImGui::DestroyContext();
    ctx->initialized = false;
}

// ---- Plugin registration ----

void ImGuiRenderPlugin::build(App& app) {
    app.insert_resource(ImGuiContext{});

    app.add_system(Schedule::Startup, init_imgui);
    app.add_system(Schedule::PreRender, begin_imgui_frame);

    // end_imgui_frame runs AFTER all panel systems, which also run in PreRender.
    // Ordering: begin_imgui_frame -> [panel systems] -> end_imgui_frame
    app.add_system(Schedule::PreRender, end_imgui_frame)
       .after(begin_imgui_frame)
       .label("end_imgui_frame");

    app.add_system(Schedule::Shutdown, shutdown_imgui);
}

} // namespace helios::editor
```

**Key points:**
- `native_handle<T>()` is the RHI escape hatch from Plan 4 (Renderer). The engine exposes it, but the engine itself never calls it with ImGui types.
- `clone_imgui_draw_data()` is a utility that deep-copies `ImDrawData` so the render thread can consume it after the main thread moves on. This is a small helper function (allocates command lists into the FramePacket's arena).
- `begin_imgui_frame` must run before any panel system. `end_imgui_frame` must run after all panel systems. Both are in `Schedule::PreRender` with explicit ordering.

**Verification:** Editor boots with an empty ImGui docking space visible. No panels yet, just the frame.

```cpp
        ? icons->get_icon("play")
        : icons->get_icon("stop");

    if (ImGui::ImageButton("##play_stop", icon_id, ImVec2(size, size))) {
        if (state->mode == EditorMode::Edit) {

            state->scene_snapshot = world->serialize_snapshot();

    ImGui::PopStyleVar(2);
```

```cpp
static void display_entity_node(
    Entity entity,
    const Tag& tag,
    const Children* children,
    EditorState& state,
    EditorCommands& commands,
    World& world
) {
    ImGui::PushID(static_cast<int>(entity.index));

    ImGuiTreeNodeFlags flags = ImGuiTreeNodeFlags_OpenOnArrow;
    if (!children || children->list.empty()) {
        flags |= ImGuiTreeNodeFlags_Leaf;
    }
    if (entity == state.selected_entity) {
        flags |= ImGuiTreeNodeFlags_Selected;
    }

    bool node_open = ImGui::TreeNodeEx(
        tag.name.c_str(), flags
    );

    // Click to select
    if (ImGui::IsItemClicked()) {
        state.selected_entity = entity;
    }

    // Drag source for reparenting
    if (ImGui::BeginDragDropSource(ImGuiDragDropFlags_None)) {
        ImGui::SetDragDropPayload("ENTITY_NODE", &entity, sizeof(Entity));
        ImGui::Text("Move %s", tag.name.c_str());
        ImGui::EndDragDropSource();
    }

    // Drop target for reparenting
    if (ImGui::BeginDragDropTarget()) {
        if (const ImGuiPayload* payload = ImGui::AcceptDragDropPayload("ENTITY_NODE")) {
            Entity dropped = *static_cast<const Entity*>(payload->Data);
            // Reparent: remove from old parent's Children, add to this entity's Children
            commands.execute(EditorCommands::UndoEntry{
                .description = "Reparent entity",
                .entity = dropped,
                .apply = [dropped, parent = entity](World& w) {
                    // Set Parent component on dropped entity
                    if (w.has<Parent>(dropped)) {
                        w.get<Parent>(dropped).entity = parent;
                    } else {
                        w.add(dropped, Parent{.entity = parent});
                    }
                    // Add to parent's Children list
                    if (!w.has<Children>(parent)) {
                        w.add(parent, Children{});
                    }
                    w.get<Children>(parent).list.push_back(dropped);
                },
                .revert = [dropped, parent = entity](World& w) {
                    // Remove from parent's Children, restore old parent
                    // (Full implementation captures old parent in the closure)
                },
            }, world);
        }
        ImGui::EndDragDropTarget();
    }

    // Right-click context menu on entity
    bool entity_deleted = false;
    if (ImGui::BeginPopupContextItem()) {
        if (ImGui::MenuItem("Create Child Entity")) {
            auto child = world.spawn();
            world.add(child, Tag{"Empty Entity"});
            world.add(child, Transform{});
            world.add(child, Parent{.entity = entity});
            if (!world.has<Children>(entity)) {
                world.add(entity, Children{});
            }
            world.get<Children>(entity).list.push_back(child);
        }
        if (ImGui::MenuItem("Delete Entity")) {
            entity_deleted = true;
        }
        ImGui::EndPopup();
    }

    // Recurse into children
    if (node_open) {
        if (children) {
            for (Entity child : children->list) {
                if (!world.is_alive(child)) continue;
                const auto& child_tag = world.get<Tag>(child);
                const Children* child_children = world.try_get<Children>(child);
                display_entity_node(child, child_tag, child_children, state, commands, world);
            }
        }
        ImGui::TreePop();
    }

    // Deferred delete (after tree rendering to avoid iterator invalidation)
    if (entity_deleted) {
        commands.execute(EditorCommands::UndoEntry{
            .description = "Delete entity",
            .entity = entity,
            .apply = [entity](World& w) { w.despawn(entity); },
            .revert = [](World& w) {
                // TODO: full entity restoration requires serializing all components
            },
        }, world);
        if (state.selected_entity == entity) {
            state.selected_entity = Entity::INVALID;
        }
    }

    ImGui::PopID();
}
```

```cpp
// ---- Reflection-based component drawing ----
// Uses qlibs/reflect to iterate all fields of an aggregate component
// and dispatch to the correct draw_field overload.

template<typename T>
static bool draw_component_fields(T& component) {
    bool any_modified = false;
    reflect::for_each([&](auto I) {
        constexpr auto name = reflect::member_name<I>(T{});
        auto& field = reflect::get<I>(component);

        using FieldType = std::remove_reference_t<decltype(field)>;

        ImGui::PushID(static_cast<int>(I));

        // Special case: fields named "color" use ColorEdit
        bool is_color = (std::string_view{name}.find("color") != std::string_view::npos);

        bool modified = false;
        if constexpr (std::is_same_v<FieldType, glm::vec3>) {
            if (is_color) {
                modified = draw_color_field(name, field);
            } else {
                modified = draw_field(name, field);
            }
        } else if constexpr (std::is_same_v<FieldType, glm::vec4>) {
            if (is_color) {
                modified = draw_color_field(name, field);
            } else {
                modified = draw_field(name, field);
            }
        } else {
            modified = draw_field(name, field);
        }

        if (modified) any_modified = true;

        ImGui::PopID();
    }, component);
    return any_modified;
}

// ---- Special Transform drawing (uses vec3 controls with XYZ buttons) ----

static bool draw_transform(Transform& t) {
    bool modified = false;

    draw_vec3_control("Position", t.position, 0.0f);
    modified |= ImGui::IsItemDeactivatedAfterEdit();

    glm::vec3 euler = glm::degrees(glm::eulerAngles(t.rotation));
    draw_vec3_control("Rotation", euler, 0.0f);
    if (ImGui::IsItemDeactivatedAfterEdit()) {
        t.rotation = glm::quat(glm::radians(euler));
        modified = true;
    }

    draw_vec3_control("Scale", t.scale, 1.0f);
    modified |= ImGui::IsItemDeactivatedAfterEdit();

    return modified;
}

// ---- Component section template ----

template<typename T>
static void draw_component_section(
    const char* name,
    Entity entity,
    World& world,
    EditorCommands& commands
) {
    if (!world.has<T>(entity)) return;

    const ImGuiTreeNodeFlags flags =
        ImGuiTreeNodeFlags_DefaultOpen | ImGuiTreeNodeFlags_Framed |
        ImGuiTreeNodeFlags_SpanAvailWidth | ImGuiTreeNodeFlags_AllowItemOverlap |
        ImGuiTreeNodeFlags_FramePadding;

    ImGui::PushStyleVar(ImGuiStyleVar_FramePadding, ImVec2{4, 4});
    ImGui::Separator();
    bool open = ImGui::TreeNodeEx(
        reinterpret_cast<void*>(static_cast<uintptr_t>(typeid(T).hash_code())),
        flags, "%s", name
    );

    // "+" button for component settings
    ImVec2 region = ImGui::GetContentRegionAvail();
    float line_height = GImGui->Font->FontSize + GImGui->Style.FramePadding.y * 2.0f;
    ImGui::SameLine(region.x - line_height * 0.5f);
    if (ImGui::Button("+", ImVec2{line_height, line_height})) {
        ImGui::OpenPopup("ComponentSettings");
    }
    ImGui::PopStyleVar();

    bool remove = false;
    if (ImGui::BeginPopup("ComponentSettings")) {
        if (ImGui::MenuItem("Remove component")) remove = true;
        ImGui::EndPopup();
    }

    if (open) {
        auto& component = world.get<T>(entity);

        // Capture old value before editing
        T old_value = component;

        bool modified = false;
        if constexpr (std::is_same_v<T, Transform>) {
            modified = draw_transform(component);
        } else {
            modified = draw_component_fields(component);
        }

        // If modified, record undo entry
        if (modified) {
            T new_value = component;
            // Revert to old, then let EditorCommands apply new
            component = old_value;
            commands.set<T>(entity, world, new_value, std::string("Modify ") + name);
        }

        ImGui::TreePop();
    }

    if (remove) {
        commands.execute(EditorCommands::UndoEntry{
            .description = std::string("Remove ") + name,
            .entity = entity,
            .apply = [entity](World& w) { w.remove<T>(entity); },
            .revert = [entity, val = world.get<T>(entity)](World& w) {
                w.add(entity, val);
            },
        }, world);
    }
}

void inspector_panel(
    Res<EditorState> state,
    ResMut<EditorCommands> commands,
    ResMut<World> world
) {
    if (!state->show_inspector) return;

    ImGui::Begin("Inspector", &const_cast<EditorState&>(*state).show_inspector);

    Entity selected = state->selected_entity;
```

```cpp
#include <helios/assets/asset_server.h>
```

```cpp
void viewport_panel(
    ResMut<EditorState> state,
    Res<RenderContext> render_ctx,
    EventWriter<ViewportResized> resize_events,
    Res<AssetServer> assets,
    Commands cmd,
    ResMut<World> world
) {
    if (!state->show_viewport) return;

    ImGui::PushStyleVar(ImGuiStyleVar_WindowPadding, ImVec2{0, 0});
    ImGui::Begin("Viewport", &state->show_viewport,
        ImGuiWindowFlags_NoDecoration | ImGuiWindowFlags_NoScrollbar |

    // Track focus/hover state for editor camera and gizmo input
    state->viewport_focused = ImGui::IsWindowFocused();
    state->viewport_hovered = ImGui::IsWindowHovered();

    // Get the scene texture from the render thread's output
    ImTextureID scene_texture = render_ctx->scene_texture_imgui_id();
    auto viewport_size = ImGui::GetContentRegionAvail();

    uint32_t new_width = static_cast<uint32_t>(viewport_size.x);
    uint32_t new_height = static_cast<uint32_t>(viewport_size.y);

    if (new_width != state->viewport_width || new_height != state->viewport_height) {
        state->viewport_width = new_width;
        state->viewport_height = new_height;

        // Fire resize event so the render thread can recreate framebuffers
        if (new_width > 0 && new_height > 0) {
            resize_events.send(ViewportResized{
                .width = new_width,
                .height = new_height,
            });
        }
    }

    // Render the scene texture
    if (scene_texture) {
        ImGui::Image(scene_texture, viewport_size);
    }

    // Drag-drop target: drop assets from content browser to create entities
    if (ImGui::BeginDragDropTarget()) {
        if (const ImGuiPayload* payload = ImGui::AcceptDragDropPayload("CONTENT_BROWSER_ITEM")) {
            auto dropped_path = *static_cast<const std::filesystem::path*>(payload->Data);
            std::string ext = dropped_path.extension().string();

            // Mesh files: create entity with MeshRenderer
            if (ext == ".gltf" || ext == ".glb" || ext == ".fbx" || ext == ".FBX") {
                auto handle = assets->get_or_import(dropped_path);
                auto entity = world->spawn();
                world->add(entity, Tag{dropped_path.stem().string()});
                world->add(entity, Transform{});
                world->add(entity, MeshRenderer{.mesh = handle});
                state->selected_entity = entity;
            }
        }
        ImGui::EndDragDropTarget();
    }

    // Store viewport bounds for mouse picking and gizmo rect
    auto window_pos = ImGui::GetWindowPos();
    auto window_size = ImGui::GetWindowSize();
    state->viewport_bounds_min = glm::vec2{window_pos.x, window_pos.y};
    state->viewport_bounds_max = glm::vec2{
        window_pos.x + window_size.x,
        window_pos.y + window_size.y
    };

    ImGui::End();
    ImGui::PopStyleVar();
```

```cpp
#include "gizmo_system.h"
#include "../editor_state.h"
#include "../editor_commands.h"

#include <helios/ecs/components.h>
#include <helios/math/math.h>

#include <imgui.h>
#include <ImGuizmo.h>

#include <glm/glm.hpp>
#include <glm/gtc/type_ptr.hpp>

namespace helios::editor {

// Map EditorState gizmo operation to ImGuizmo operation
static ImGuizmo::OPERATION to_imguizmo_op(GizmoOperation op) {
    switch (op) {
        case GizmoOperation::Translate: return ImGuizmo::TRANSLATE;
        case GizmoOperation::Rotate:    return ImGuizmo::ROTATE;
        case GizmoOperation::Scale:     return ImGuizmo::SCALE;
    }
    return ImGuizmo::TRANSLATE;
}

static ImGuizmo::MODE to_imguizmo_mode(GizmoSpace space) {
    switch (space) {
        case GizmoSpace::Local: return ImGuizmo::LOCAL;
        case GizmoSpace::World: return ImGuizmo::WORLD;
    }
    return ImGuizmo::LOCAL;
}

void gizmo_system(
    ResMut<EditorState> state,
    ResMut<EditorCommands> commands,
    Query<const Transform, const Camera, With<ActiveCamera>> camera_query,
    ResMut<World> world
) {
    // Only draw gizmos in edit mode
    if (state->mode != EditorMode::Edit) return;

    Entity selected = state->selected_entity;
    if (!selected || !world->is_alive(selected)) return;
    if (!world->has<Transform>(selected)) return;

    // Need a camera for view/projection matrices
    bool has_camera = false;
    glm::mat4 view_matrix{1.0f};
    glm::mat4 proj_matrix{1.0f};

    for (auto [cam_transform, camera] : camera_query) {
        view_matrix = glm::inverse(cam_transform.to_mat4());
        proj_matrix = camera.projection_matrix();
        has_camera = true;
        break;
    }
    if (!has_camera) return;

    // Configure ImGuizmo for this viewport
    ImGuizmo::SetOrthographic(false);
    ImGuizmo::SetDrawlist();

    // Set gizmo rect to match the viewport panel bounds
    ImGuizmo::SetRect(
        state->viewport_bounds_min.x,
        state->viewport_bounds_min.y,
        state->viewport_bounds_max.x - state->viewport_bounds_min.x,
        state->viewport_bounds_max.y - state->viewport_bounds_min.y
    );

    // Get the entity's transform matrix
    auto& transform = world->get<Transform>(selected);
    glm::mat4 model = transform.to_mat4();

    // Snap values
    float snap_value = 0.0f;
    if (state->gizmo_snap) {
        switch (state->gizmo_op) {
            case GizmoOperation::Translate: snap_value = state->translate_snap; break;
            case GizmoOperation::Rotate:    snap_value = state->rotate_snap; break;
            case GizmoOperation::Scale:     snap_value = state->scale_snap; break;
        }
    }
    float snap_values[3] = {snap_value, snap_value, snap_value};

    // Manipulate
    ImGuizmo::Manipulate(
        glm::value_ptr(view_matrix),
        glm::value_ptr(proj_matrix),
        to_imguizmo_op(state->gizmo_op),
        to_imguizmo_mode(state->gizmo_space),
        glm::value_ptr(model),
        nullptr,
        state->gizmo_snap ? snap_values : nullptr
    );

    if (ImGuizmo::IsUsing()) {
        // Decompose the modified matrix back into position/rotation/scale
        glm::vec3 new_position, new_rotation, new_scale;
        helios::math::decompose_transform(model, new_position, new_rotation, new_scale);

        // Build the new Transform
        Transform new_transform = transform;
        new_transform.position = new_position;
        new_transform.rotation = glm::quat(new_rotation);  // euler to quat
        new_transform.scale = new_scale;

        // Apply via EditorCommands (undo support)
        // We use set<T> only on gizmo release to avoid flooding the undo stack.
        // During dragging, apply directly. On release, record the full delta.
        transform = new_transform;
    }

    // On gizmo release, record the undo entry for the full drag operation
    static bool was_using = false;
    static Transform drag_start_transform;

    if (ImGuizmo::IsUsing() && !was_using) {
        // Drag started: capture starting state
        drag_start_transform = transform;
    }

    if (!ImGuizmo::IsUsing() && was_using) {
        // Drag ended: record undo entry for the complete operation
        Transform final_transform = transform;
        commands->execute(EditorCommands::UndoEntry{
            .description = "Gizmo transform",
            .entity = selected,
            .apply = [selected, final_transform](World& w) {
                w.get<Transform>(selected) = final_transform;
            },
            .revert = [selected, start = drag_start_transform](World& w) {
                w.get<Transform>(selected) = start;
            },
        }, *world);
    }

    was_using = ImGuizmo::IsUsing();
}

} // namespace helios::editor
```

**Differs from current `Viewport::RenderImpl` gizmo code:** Extracted into its own system. Uses `EditorState` for gizmo mode instead of local member. Undo support via `EditorCommands` (current code has none). Captures start/end of drag for a single undo entry per gizmo operation (not per-frame). No singleton access.

**Verification:** Select entity, gizmo appears. W/E/R switch modes. Ctrl enables snap. Drag gizmo, Ctrl+Z reverts the full drag.

```cpp
#include "editor_state.h"

#include <glm/gtx/quaternion.hpp>

namespace helios::editor {

void setup_editor_camera(
    Commands cmd,
    ResMut<World> world
) {
    // Create editor camera entity
    auto entity = world->spawn();
    world->add(entity, Tag{"EditorCamera"});

    EditorCameraState cam_state;

    Transform transform{};
    transform.position = cam_state.initial_position;
    transform.rotation = glm::quat(glm::radians(cam_state.initial_rotation_euler));
    transform.scale = glm::vec3{1.0f};
    world->add(entity, transform);

    Camera camera{};
    camera.fov_y = 45.0f;
    camera.near_plane = 0.1f;
    camera.far_plane = 500.0f;
    camera.projection = ProjectionType::Perspective;
    world->add(entity, camera);

    // Mark as active camera
    world->add(entity, ActiveCamera{});

    // Insert camera controller state as a resource
    world->insert_resource(std::move(cam_state));
}

void update_editor_camera(
    Res<EditorState> editor_state,
    Res<Input> input,
    Res<Time> time,
    ResMut<EditorCameraState> cam_state,
    Query<Transform, Camera, With<ActiveCamera>> camera_query
) {
    // Only control camera in Edit mode when viewport is focused
    if (editor_state->mode != EditorMode::Edit) return;
    if (!editor_state->viewport_focused) return;

    float dt = time->delta();

    for (auto [transform, camera] : camera_query) {
        // ---- Orbit (right-mouse-drag) ----
        if (input->mouse_held(MouseButton::Right)) {
            if (cam_state->first_right_click) {
                cam_state->last_mouse_pos = input->mouse_position();
                cam_state->first_right_click = false;
            }

            glm::vec2 current_pos = input->mouse_position();
            cam_state->mouse_delta = cam_state->last_mouse_pos - current_pos;
            cam_state->last_mouse_pos = current_pos;

            // Apply rotation around focal point
            glm::vec3 euler = glm::eulerAngles(transform.rotation);
            euler.y += cam_state->mouse_delta.x * cam_state->sensitivity * dt;
            euler.x += cam_state->mouse_delta.y * cam_state->sensitivity * dt;
            euler.x = glm::clamp(euler.x, glm::radians(-89.0f), glm::radians(89.0f));
            transform.rotation = glm::quat(euler);
        } else {
            cam_state->first_right_click = true;
        }

        // ---- WASD Movement ----
        glm::vec3 forward = transform.rotation * glm::vec3{0, 0, -1};
        glm::vec3 right = transform.rotation * glm::vec3{1, 0, 0};
        glm::vec3 up = glm::vec3{0, 1, 0};

        cam_state->velocity = glm::vec3{0.0f};

        if (input->mouse_held(MouseButton::Right)) {
            // FPS-style movement when right mouse is held
            if (input->key_held(KeyCode::W)) cam_state->velocity += forward;
            if (input->key_held(KeyCode::S)) cam_state->velocity -= forward;
            if (input->key_held(KeyCode::A)) cam_state->velocity -= right;
            if (input->key_held(KeyCode::D)) cam_state->velocity += right;
        } else {
            // Pan movement (up/down instead of forward/back)
            if (input->key_held(KeyCode::W)) cam_state->velocity += up;
            if (input->key_held(KeyCode::S)) cam_state->velocity -= up;
            if (input->key_held(KeyCode::A)) cam_state->velocity -= right;
            if (input->key_held(KeyCode::D)) cam_state->velocity += right;
        }

        if (glm::length(cam_state->velocity) > 0.001f) {
            cam_state->velocity = glm::normalize(cam_state->velocity) * cam_state->speed * dt;
            transform.position += cam_state->velocity;
        }

        // ---- Scroll Zoom ----
        float scroll = input->scroll_delta().y;
        if (std::abs(scroll) > 0.001f) {
            transform.position += forward * scroll * cam_state->zoom_speed;
        }

        break; // Only one active camera
    }
}

} // namespace helios::editor
```

**Differs from current `EditorCamera`:** No `Ref<Camera>` or `Ref<Scene>`. No `Input::GetMouseX()` statics. Reads from `Input` resource (Plan 3). Writes directly to the `Transform` component on the `ActiveCamera` entity via ECS query. No `UpdateKeyState` method -- uses `input->key_held()` which handles key state internally. Speed scales with zoom distance (same concept as current code, but reads from transform position).

**Verification:** WASD moves camera. Right-click-drag orbits. Scroll zooms. Only active when viewport is focused and in Edit mode.

```cpp
// This system runs in PreUpdate and controls whether physics+scripts should tick.
// It does this by inserting/removing a PhysicsEnabled resource that the PhysicsPlugin checks.
static void editor_mode_gate(
    Res<EditorState> state,
    ResMut<World> world
) {
    bool should_simulate = (state->mode == EditorMode::Play || state->mode == EditorMode::Simulate);

    if (should_simulate && !world->has_resource<PhysicsEnabled>()) {

        world->insert_resource(ScriptsEnabled{});
    } else if (!should_script && world->has_resource<ScriptsEnabled>()) {
        world->remove_resource<ScriptsEnabled>();
    }
}
```
